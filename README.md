# Wall Soft Stone · Soft Stone Sdn Bhd

Product webpage for Wall Soft Stone (MCM flexible stone): 29 textures in 7 series, 168 colours and 64 real-sheet photos, built from the 2026 MCM soft stone catalogues.

## View it

Open `index.html` in a browser. It is a static page with no build step, so it can be hosted as-is (for example on GitHub Pages).

## Files

- `index.html`: the page (layout, styles and scripts)
- `assets/data.js`: series, textures, colour names, codes and thickness; edit names or codes here
- `images/`: room photos, texture close-ups, colour swatches and real-sheet photos

## Contact details

The sample list can be sent by WhatsApp or email once contact details are filled in near the top of the script in `index.html`:

```js
const CONTACT = { whatsapp: "60123456789", email: "sales@yourcompany.com.my", website: "https://yourcompany.com.my" };
```

Buttons stay hidden while a value is empty.
